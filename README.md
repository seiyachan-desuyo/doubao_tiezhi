# 豆包工位造景贴纸 Demo

奶油治愈风的线上造景贴纸小玩具，灵感来自《贴纸小角落 Little Corners》。打开网页即可在纯白拼贴区选贴纸、拖拽、缩放、旋转、翻转、调层级、删除，支持撤销重做与截图导出，全部数据保存在浏览器本地。

## 目录结构

- `index.html`：单文件应用，原生 HTML/CSS/JS，无框架无构建
- `assets/`：网页运行所需全部素材（角色、物品、场景贴纸与背景图），与 `index.html` 同级，引用均为相对路径
- `背景/`、`角色/`、`素材说明.md`：原始素材与整理说明

## 运行方式

直接双击打开 `index.html` 即可（建议 Chrome / Edge / Safari 最新版）。

也可以在仓库 Settings → Pages 中选择分支根目录发布，获得在线访问链接。

## 玩法

- 左侧贴纸纸分为角色、物品、场景三个分区，场景内按封面二级分类
- 揭下的贴纸贴到拼贴区后可自由拖动；粉点缩放、黄点旋转，浮动工具条支持翻转与层级调整
- 首屏的成品工位是一张默认贴纸，点击即可收起，之后进入空白自由拼贴
- 右下角相机按钮可导出当前作品为 PNG
